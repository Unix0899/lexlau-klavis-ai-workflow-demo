## Principles applied

1. **Independent implementation.** Generic architecture written for this demo. Wherever it looks like a
   real system, that is because the problem (document to structured case) is common, not because
   anything was copied.
2. **Synthetic only.** Every person, company, municipality, reference, amount and document is invented and
   generated by `scripts/synthetic_documents.py`. Court names are generic public institution labels.
3. **Claim → evidence.** Every number in the README and on the portfolio page is produced by code in
   this repository (SQL views, test runs, reconciliations).
4. **Honest role.** Real experience: an AI Engineer & Data Analyst intern who worked under technical
   supervision. This repository demonstrates methods and skills. It is not the production system.
